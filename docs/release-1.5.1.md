# ResumeDesk v1.5.1 发布报告

本地交付 Windows x64 NSIS 安装包和可用于 GitHub 的源码包。本轮在 Windows 11 和 WebView2 上使用独立资料目录与虚构招聘记录验收。

## 悬浮待办

旧版悬浮窗保留了 Tauri 默认的系统装饰，WebView 同时绘制置顶、最小化和隐藏控件。新版由自定义标题栏显示一组控件。标题区使用 WebView2 原生拖动区域；支持较旧 WebView 的 Tauri 拖动入口限于悬浮窗口。控件区独立接收点击，缩放使用 Tauri 原生边框。

窗口沿用现有的 `widget_settings`。恢复尺寸时先按目标显示器的缩放换算，再把窗口放入其工作区。原保存坐标落在已断开的显示器时，使用当前主显示器。SQLite 仍使用 V11，旧版保存的窗口位置和招聘数据可继续读取。

| 修改位置 | 内容 |
| --- | --- |
| `src-tauri/src/desktop.rs` | 悬浮窗口装饰、原生缩放、位置恢复和 DPI 单元测试 |

| `scripts/third-party-notices.mjs`、`THIRD_PARTY_NOTICES.txt` | 来自锁定依赖与资源包的许可文字和版本来源 |

## 验收与构建

- TypeScript 类型检查、Vite 生产构建、Rust 格式与 `cargo check` 通过。执行 36 项 Rust 测试和 2 项 Node 测试。
- Windows 桌面回归覆盖简历批量导入、PDF 预览和中英文搜索、多岗位独立申请、JD 编辑、聊天授权、资料库检索、面试准备、提醒及个性化布局。AI 与联网搜索使用本机模拟端点。
- 实测标题区域移动窗口，分别拖动上边和左边至最小尺寸。验证置顶切换、悬浮窗和主窗口最小化、隐藏后重开，以及待办创建、完成、删除的跨窗同步。重启后，原生窗口回到保存的屏幕位置和 280 × 280 逻辑像素的内容尺寸。原生窗口截图使用隔离资料。
- 几何单元测试覆盖 100%、125%、150% 缩放和原显示器缺失。WebView 模拟三种像素比例时，最小尺寸下三枚按钮仍各自可点。真实多显示器热拔插、系统 125% / 150% 缩放和 Windows 10 在目标设备复验。
- Tauri 已构建 Windows x64 程序和 NSIS 安装包，直接运行版能创建空白 V11 资料库。隔离目录静默安装、启动和卸载通过，卸载后 V11 测试数据库完整保留。当前沙箱内未观察到开始菜单、桌面快捷方式和卸载注册项，需要在普通 Windows 用户环境复验。安装包未签名。`proc-macro-error2` 在当前 Rust 工具链产生未来兼容性提示。
- 两个 GitHub Actions 工作流已在本地检查 YAML、事件和权限，构建命令已在本机执行。GitHub 托管运行结果待仓库接收本版本后验证。
- 本机 npm 网络不可达，pnpm 的干净安装校验缺少离线注册表元数据。构建和测试使用现有锁文件及已缓存依赖，工作流保留标准的冻结锁文件安装。

## 公开文件与授权

交付源码包包含 109 个通过清单和内容核对的文件，包括应用代码、文档、两份依赖锁文件、数据库迁移、虚构演示材料和本地测试。核对了常见凭据、机器绝对路径和截图元数据，压缩包逐文件校验与源码一致。对于已跟踪的文件，需要检查 Git 索引和对应提交历史。当前开发源目录没有 Git 元数据，本轮检查范围为本地项目与交付源码包。

`.gitignore` 排除数据库及日志、凭据、上传原件、备份、IDE 配置、安装包和构建缓存。演示文件与运行资料库分开，应用首次启动创建空白库。用户的现有数据库在本轮验收过程中保留。

项目还未声明公开源码许可，由所有者选择。安装包携带第三方许可声明；说明列出锁定的 npm 和 Rust 包、随包提供的许可、PDF 资源许可和对应的版本来源。部分依赖包把许可声明放在上游源码中，具体包版本在声明里可查。 [第三方声明](../THIRD_PARTY_NOTICES.txt)

## Windows 复验步骤

1. Windows「设置 → 系统 → 显示」依次选择 100%、125%、150% 缩放。每次通过「小工具 → 待办事项 → 打开桌面待办」查看，分别检查默认与最小尺寸下三枚按钮有无重叠，标题能否拖动，四边能否缩放。
2. 切换置顶并将主窗口最小化，确认悬浮待办仍可点击。依次测试悬浮待办自身的最小化和隐藏，在主窗口重开后核对位置、尺寸和任务列表。
3. 在隔离资料库新增一条虚构待办，分别从浮窗完成并从主窗口删除。验证两个窗口同步。将悬浮窗移到副屏并重启，记录位置；移除副屏后再次打开，确认窗口落回可用工作区。
4. 在测试账户安装，核对版本、应用图标和开始菜单入口，再用安装结束页的选项检查桌面快捷方式。卸载时保持「删除应用数据」未选中，确认资料保留。

公开发行前由所有者决定主项目许可证与签名安排。源码进入仓库后，版本标签 `v1.5.1` 可生成安装包作为 Actions 产物，维护者再将安装包和 SHA-256 校验文件放入 GitHub Releases。
